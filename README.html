SAF-Predict User Guide

Predict mass-based and volumetric net heat of combustion, density, solid–liquid phase-transition temperature, boiling point, flash point, and kinematic viscosity at 40 °C from seven molecular descriptors.

Quick start

  1. Open index.html in a desktop browser with JavaScript enabled. No installation, Python environment, or internet connection is required. This release does not include a browser/operating-system compatibility matrix.
  2. For Windows only, Start_SAF_Predictor.bat is an optional shortcut that opens the same file.
  3. Enter X01–X07 under “Single-compound prediction” and confirm that the compound is a neutral, single-component pure hydrocarbon.
  4. Interpret every point estimate with its empirical prediction interval, applicability-domain (AD) distance percentile, and any warnings.
  5. For batch prediction, start from examples/batch_input_template.csv.

Limitations

Y04 performed poorly on the internal holdout (R² = −0.021; MAE = 25.2 °C; n = 10). Do not use Y04 alone to rank or select compounds; experimental confirmation is required.
  • The model applies only to pure hydrocarbon molecules represented using the documented descriptor definitions; it does not apply to mixtures, finished fuels, heteroatom-containing compounds, ions, or polymers.
  • Y02 is calculated from predicted Y01 × predicted Y03 rather than fitted independently.
  • Y04 is the pure-compound solid–liquid phase-transition temperature, not the freezing point of a finished fuel; Y05 is not a distillation curve, and Y07 is not a low-temperature aviation-fuel viscosity specification.
  • This release is a provenance-aware hybrid dataset, not an all-experimental database. Record-property value origins, source links, and retained condition or method notes are provided in data/provenance_long.csv and data/references.csv.
  • Nine of the ten records in the internal holdout set (eight of nine unique molecular formulae) share a formula with the development set. This internal holdout evaluation is not independent external, prospective, or experimental validation.
  • The applicability-domain (AD) distance percentile reports position in the development-set reference-distance distribution; it is not a calibrated prediction-error probability.
  • The application predicts pure-compound physicochemical properties only. It does not assess fuel-specification compliance, blend performance, sustainability, synthesis, safety, emissions, cost, or engine performance.

Traceability and release artifacts

This release includes the browser application, fixed serialized model artifacts, internal holdout evaluation outputs, and release checks. According to the recorded workflow, model and hyperparameter selection used the development set before the internal holdout evaluation. Current hashes identify artifacts but do not independently establish pre-evaluation chronology.

The serialized public model object omits molecule names, molecular formulae, original development-record identifiers, and bilingual display metadata. X01–X07 development vectors remain for nearest-neighbour applicability-domain calculations. The repository separately provides the development and held-out data, record-property provenance, reference registry, fixed grouped folds, training workflow, environment files, and evaluation checks.
